---
title: "Binary Codes and Programs"
id: "2802_B_003_A"
---

Each functional system operates through a two-sided code: legal/illegal, pay/not pay, true/false, govern/be governed. The code defines what belongs to the system. Programs are the rules that determine how the code is applied in specific cases (statutes, methods, budgets). Programs change; codes are more stable. Every communication must fall on one side - there is no neutral third value.
