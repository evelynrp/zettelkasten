---
title: "Description serves users"
id: "5730_D"
---

The purpose of archival description is to help users find materials. A title or scope note that does not accurately reflect what is in the item - such as packet-level language applied to a single image - directly undermines this purpose. Description is values-driven and iterative, not merely technical formatting.
