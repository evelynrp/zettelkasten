# zettelkasten

This is a digital copy of my analog zettelkasten (note card box).

I started keeping a zettelkasten in late 2025, during my graduate studies. It has helped me write many, many papers.

This zettelkasten does not utilize hyperlinks, tags, or any other features common in digital zettelkasten or personal knowledge management systems (pkms). It is a digitization of the actual physical index cards on which I write my notes.

This zettelkasten is intended for my own use. As such, the language and/or intent of certain notes may be opaque. I nevertheless hope you may find some value in it.
